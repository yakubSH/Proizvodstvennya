# Информационная система учета оплаты тарифов

Проект разработан на C#/.NET и состоит из библиотеки классов, пользовательского интерфейса и слоя хранения данных.

## Состав решения

- `TariffPaymentAccounting.Core` - модели и бизнес-логика: клиенты, тарифы, платежи, расчет начислений, долга и переплаты.
- `TariffPaymentAccounting.Storage` - хранение данных в JSON-файле.
- `TariffPaymentAccounting.App` - Windows Forms интерфейс.

## Как запускать

Самый простой вариант:

```text
start-app.cmd
```

Если папка `publish` уже создана, скрипт запустит готовый `publish\TariffPaymentAccounting.exe`.
Если опубликованного exe еще нет, скрипт запустит приложение через `dotnet run`.

## Как собрать обычный exe

```text
build-exe.cmd
```

После сборки готовый файл будет здесь:

```text
publish\TariffPaymentAccounting.exe
```

Этот файл можно запускать двойным щелчком.

## Возможности приложения

- учет клиентов с лицевыми счетами, телефонами, адресами и назначенными тарифами;
- добавление и редактирование тарифов;
- архивирование тарифов;
- прием оплат за выбранный месяц;
- удаление ошибочно внесенных платежей с подтверждением;
- отчет по начислениям, оплатам, долгу и переплате;
- экспорт отчета в CSV;
- автоматическое сохранение данных после операций.

## Где хранятся данные

```text
%AppData%\TariffPaymentAccounting\tariff-payments.json
```

Демонстрационные данные создаются только при первом запуске, когда файла данных еще нет.

## Проверка сборки
